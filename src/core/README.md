# Логическое ядро

Чистый TypeScript без React, Redux, HTTP и знания о конкретном магазине:
доменные типы (товар, вариант, категория, позиция корзины) и правила
(слияние позиций, лимит количества, сверка цен перед заказом).

Границы проверяет ESLint (`no-restricted-imports` в `eslint.config.js`).
Наполняется со следующего этапа.
